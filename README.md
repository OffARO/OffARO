# OffARO

Downloads, shared configurations and helper scripts for **OffARO** (Offline APRS Radio Operation), the desktop app for APRS messaging, mapping and search-and-rescue coordination.

- **Download the app:** [Releases](https://github.com/OffARO/OffARO/releases) — each release lists which file to pick for Windows, Mac, Linux and Raspberry Pi.
- **Website and manuals:** <https://www.offaro.io>
- **Bugs and wishes:** [OffARO-Feedback](https://github.com/OffARO/OffARO-Feedback)

| Folder | What it holds |
| --- | --- |
| [`configs/`](configs) | Shared map configurations that OffARO can subscribe to (*Settings → Configuration → Shared configurations*). |
| [`scripts/`](scripts) | Helper programs that run on **other machines** than OffARO: a drone Remote ID receiver for a Raspberry Pi, a remote station controller for the Device Control Panel, and bridges that feed positions into OffARO. |

The application source is maintained in a separate repository; the files here are the ones users need in the field.
